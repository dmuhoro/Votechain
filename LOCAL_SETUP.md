# Local Setup Guide: VoteChain Kenya

Follow these commands to extract the project, install dependencies, and open it in your IDE.

## 1. Extract and Navigate
Assuming you have downloaded `votechain.zip` to your **Downloads** folder:

### On macOS / Linux:
```bash
cd ~/Downloads
unzip votechain.zip
cd votechain
```

### On Windows (PowerShell):
```powershell
Expand-Archive -Path "$HOME\Downloads\votechain.zip" -DestinationPath "$HOME\Downloads"
cd "$HOME\Downloads\votechain"
```

---

## 2. Install Dependencies
This project uses NPM workspaces. You can install all dependencies for the root, backend, frontend, and contracts in one go:

```bash
npm install
```

---

## 3. Configure Environment Variables
You need to create `.env` files from the examples provided. Run these commands to copy the templates:

### On macOS / Linux:
```bash
cp packages/backend/.env.example packages/backend/.env
cp packages/frontend/.env.example packages/frontend/.env
cp packages/contracts/.env.example packages/contracts/.env
```

### On Windows (PowerShell):
```powershell
copy packages/backend/.env.example packages/backend/.env
copy packages/frontend/.env.example packages/frontend/.env
copy packages/contracts/.env.example packages/contracts/.env
```

*Note: You will need to fill in these `.env` files with your Supabase and Infura/Alchemy credentials later.*

---

## 4. Open in Your IDE
If you use **VS Code**, you can open the entire project with:

```bash
code .
```

---

## 5. Development Workflow
To run the backend and frontend concurrently for development:

```bash
npm run dev
```

- **Frontend:** http://localhost:5173
- **Backend:** http://localhost:3001
