# Travel & Sprints

Each sprint produces one file `docs/sprints/sprint-<N>-<theme>.md` using the shared anatomy:

1. **Theme** (one sentence) + **Result** paragraph (verifiable numbers)
2. **Summary table**: `Capability | Status | Evidence`
3. **Part sections** per work-stream (Root Cause / Solution / Files)
4. **Verification Evidence** table (`Suite | Target | Result | Status`)
5. **Status checklist** — every claim is a checkbox
6. **Honest Boundaries / Next Steps**

Every claim in a sprint file must have evidence in `docs/evidence/` (Constitution Article VII).
